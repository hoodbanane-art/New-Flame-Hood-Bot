# Roadmap

The roadmap reflects intended work, not delivery guarantees. Community feedback and Roblox or Discord API changes can alter priorities.

## Stable foundation

- [x] Supported Open Cloud moderation operations
- [x] Guild, role, user, and protected-account authorization
- [x] Authenticated and replay-resistant kick protocol
- [x] Automated tests, CI, CodeQL, and dependency review
- [x] Guided setup and Docker deployment
- [x] Security and contribution policies

## Next

- [ ] Moderation case IDs and structured action history
- [ ] Warning and staff-note workflows
- [ ] Configurable command-level permissions
- [ ] Health and readiness reporting for container platforms
- [ ] Automated Roblox protocol compatibility tests
- [ ] Consent-based deployment and usage metrics

## Later

- [ ] Multi-guild and multi-universe configuration
- [ ] Appeal workflow integrations
- [ ] Reusable TypeScript package for Roblox moderation APIs
- [ ] Localization
- [ ] Additional deployment templates

Open a feature request describing the operator problem before implementing a roadmap item. Security and compatibility work take priority over feature count.
