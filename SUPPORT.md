# Support

## Setup and usage

Start with the [Quick Start](README.md#quick-start), [Deployment Guide](docs/DEPLOYMENT.md), and [Troubleshooting Guide](docs/TROUBLESHOOTING.md).

When Discussions are available, use them for configuration questions, deployment advice, and ideas that are not yet actionable bug reports. Use GitHub issues only for reproducible bugs and scoped feature requests.

Support is provided on a best-effort community basis. Include the release or commit, deployment method, sanitized error output, and reproduction steps.

## Security

Do not request security help in a public issue when doing so would reveal an exploit or credential. Follow [SECURITY.md](SECURITY.md) and use GitHub's private vulnerability-reporting flow.

## Roblox and Discord platform support

For account ownership, API-key creation, Discord application access, platform outages, or enforcement decisions, use the official Roblox or Discord support channels. This project cannot recover platform accounts or override platform policy.
